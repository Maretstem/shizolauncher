# Вход через аккаунт Microsoft — как включить

Лицензионный вход в ShizoLauncher уже написан, но выключен: Microsoft пускает к Minecraft только приложения,
которые одобрила Mojang. Нужно один раз зарегистрировать лаунчер и дождаться одобрения. Делает это владелец
лаунчера, игрокам ничего делать не надо — они получат вход обычным обновлением.

Пока вход выключен, игроки в окне «Добавить аккаунт» видят кнопку «Microsoft — как войти с лицензией?» со справкой
и предложением войти через Ely.by.

## Шаг 1. Зарегистрировать приложение в Azure (бесплатно, 10 минут)

1. Открой <https://portal.azure.com> и войди своим аккаунтом Microsoft. Если попросит создать каталог (tenant) —
   соглашайся, это бесплатно; карта не нужна для регистрации приложения.
2. В поиске сверху набери **App registrations** → **New registration**.
3. Заполни:
   - **Name**: `ShizoLauncher`
   - **Supported account types**: *Personal Microsoft accounts only*
     (только личные аккаунты — именно на них покупают Minecraft).
   - **Redirect URI**: платформа *Public client/native (mobile & desktop)*, адрес
     `https://login.microsoftonline.com/common/oauth2/nativeclient`
4. Нажми **Register**. На открывшейся странице скопируй **Application (client) ID** — строка вида
   `1a2b3c4d-....`. Это не секрет, его можно хранить в открытом репозитории.
5. Слева **Authentication** → внизу **Allow public client flows** → **Yes** → **Save**.

## Шаг 2. Попросить Mojang одобрить приложение

1. Открой форму <https://aka.ms/mce-reviewappid>.
2. Укажи client ID из шага 1, название `ShizoLauncher`, ссылку на репозиторий
   <https://github.com/Maretstem/shizolauncher> и почту для ответа.
3. В описании честно напиши, что это лаунчер для своего сервера, который запускает Minecraft
   для владельцев лицензии (вход через официальную страницу Microsoft, токены хранятся на компьютере игрока).
4. Жди письма. Обычно это от нескольких дней до пары недель. Пока одобрения нет, вход будет падать с ошибкой
   «приложение не одобрено» — это нормально.

## Шаг 3. Включить вход в лаунчере

1. В `launcher.config.json` впиши client ID:
   ```json
   "azureClientId": "1a2b3c4d-...."
   ```
2. Выпусти новую версию лаунчера как обычно (поменять `version` в `package.json`, коммит, тег `vX.Y.Z`).
   Игроки получат её автообновлением — кнопка «Microsoft» в «Добавить аккаунт» станет активной.

Проверить можно и до выпуска: в лаунчере **Настройки → Сервер → Azure Client ID** — вставь ID, и вход заработает
только на твоём компьютере.

## Как вход выглядит для игрока

1. «Добавить аккаунт» → **Microsoft**.
2. Открывается окно с официальной страницей входа Microsoft — почта, пароль, код двухфакторки. Пароль вводится
   на сайте Microsoft, лаунчер его не видит.
3. Окно закрывается само, аккаунт появляется в списке с лицензионным ником и скином.
   Токены хранятся зашифрованными ключом Windows и обновляются сами — входить заново не нужно.

## Частые ошибки

| Что видит игрок | Что значит | Что делать |
|---|---|---|
| «Приложение не одобрено для Minecraft» | Mojang ещё не одобрила client ID | Ждать письма из шага 2 |
| «У аккаунта нет Minecraft» | Вошли не тем аккаунтом | Войти тем, на котором куплена игра (minecraft.net → профиль) |
| «Аккаунт Xbox не создан» | У аккаунта нет профиля Xbox | Один раз зайти на xbox.com и создать профиль (бесплатно) |
| «Аккаунт ребёнка» | Семейная группа запрещает сторонние приложения | Взрослый разрешает в настройках семьи Microsoft |
| Окно входа белое или не грузится | Нет доступа к login.live.com | Проверить интернет или VPN |
